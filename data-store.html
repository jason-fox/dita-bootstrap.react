Data Store Service (data-store)

Containerized file server and REST API for document set discovery, static AST JSON serving, and search index generation.

Service Overview

The data-store service operates as the core content repository backend. It scans the shared data volume (DATA_DIR) for published documentation sets, serves JSON AST files, and builds full-text search indices.

Key Capabilities

  • Documentation Discovery — Recursively scans DATA_DIR for subdirectories containing a toc.json manifest and exposes them via GET /api/docs.
  • Static AST Asset Serving — Serves compiled topic JSON files, image assets, and Table of Contents manifests under /data/....
  • Search Index Generation — Generates an in-memory/JSON MiniSearch index (search-index.json) for each document set upon server startup.

Container Deployment & Configuration

Deploy the service using Docker Compose or a standalone Docker container without requiring local package managers:

# Launch data-store using Docker Compose:
docker compose up -d data-store

# Or run as a standalone Docker container:
docker run -d -p 4000:4000 \
  -v /path/to/data:/app/data \
  ghcr.io/jason-fox/ast-data-store:latest

Configuration Environment Variables:

PORT
HTTP port for the Express REST server (default: 4000).
DATA_DIR
Directory path containing published documentation sets (default: /app/data).
DEFAULT_LANGUAGE
Fallback IETF BCP 47 language code for document set discovery (default: en).
MAX_UPLOAD_SIZE
Max body size accepted by the POST/PUT /api/docs/<id> zip uploads (default: 100mb).
AUTH_TOKEN
Optional bearer token guarding the /api/docs/<id> and /api/chrome write routes. Unset by default, which disables auth entirely.
CHROME_CACHE_TTL_MS
How long GET /api/chrome serves chrome.json from an in-memory cache before re-reading from disk (default: 5000). PUT /api/chrome invalidates the cache immediately on write.
FEATURED_DOCS
Comma-separated doc-set ids to pin first (before priority/alphabetical) in /api/docs ordering. Unset by default.
WEB_CONCURRENCY / WORKERS
Explicit worker process count. Takes precedence over CLUSTER_MODE. Unset by default.
CLUSTER_MODE
Set to true to run one worker per CPU core when WEB_CONCURRENCY/WORKERS aren't set (default: false).

REST Endpoints

  • GET /api/docs — Returns a JSON array of all discovered documentation sets with OASIS metadata.
  • GET /api/docs/<id> — Returns the summary for one doc set. 404 if <id> doesn't exist.
