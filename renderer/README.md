# Abstract Syntax Tree Renderer

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](../LICENSE)

Next.js + react-bootstrap web application that fetches `[type, props?, ...children]` JSON AST files and renders them into real `react-bootstrap` UI components.

## Background

`renderer` provides a web portal for documentation readers and AI assistant chat users. Rather than rendering raw HTML strings, it consumes AST JSON structures generated by `org.dita-bootstrap.ast` and maps AST nodes directly to interactive `react-bootstrap` components (cards, accordions, modals, navigation bars, alerts) with syntax highlighting and dark mode theming.

## Usage

### Development Mode

```console
npm run dev
```

### Production Build & Startup

```console
npm run build
npm run start
```

Requires `data-store` running (default `http://localhost:4000`).

### Customizing Headers & Footers via DITA-OT Publishing

Layout headers and footers are specified when publishing documentation using DITA-OT build parameters:

```console
dita --input=path/to/your.ditamap \
     --format=ast-bootstrap \
     --args.hdr=path/to/custom-header.xml \
     --args.ftr=path/to/custom-footer.xml \
     --output=data-store/data/my-doc-set
```

Header XML templates (`custom-header.xml`) support XML placeholders and special roles processed at publish time:

- **`<document-title/>`**: Replaced by DITA-OT with the published map/document title.
- **`role="search"`**: Intercepted by `AstRenderer` to mount the interactive `<Search>` component.
- **`role="theme-toggle"`**: Intercepted by `AstRenderer` to mount the interactive `<DarkModeToggle>` component.
- **`role="clear-chat"`**: Intercepted by `/chat` to clear conversation history and reset context tokens.

When no custom `--args.hdr` or `--args.ftr` parameters are specified, `renderer` falls back to `data-store/data/chrome.json` for default catalog navbar (`docs-page.header`), document card templates (`docs-page.card`), AI Assistant layout trees (`chat-bot`), and default footers.

## API

### Web Portal Routes

- **`/`**: Documentation library homepage card grid listing all discovered documentation sets.
- **`/<docId>/<topicPath>`**: Dynamic doc set viewer with TOC sidebar, breadcrumbs, scrollspy, and syntax highlighting.
- **`/chat`**: Integrated AI Assistant chat portal connecting to `mcp-server`.

### Environment Variables

| Variable | Default | Description |
|---|---|---|
| `PORT` | `3000` | HTTP port for Next.js web application. |
| `BOOTSTRAP_THEME` | `"default"` | Bootswatch theme name (`journal`, `darkly`, `flatly`, `cyborg`, etc.). |
| `OPEN_GRAPH_URL` | *(empty)* | Base URL used to generate `og:url` and `twitter:url` metadata tags. |
| `CUSTOM_CSS_PATH` | *(null)* | Path or URL to an additional custom stylesheet. |
| `NEXT_PUBLIC_DATA_URL` | `http://localhost:4000/data` | Base URL for JSON AST static files. |
| `NEXT_PUBLIC_API_URL` | `http://localhost:4000/api` | Base URL for data-store API routes. |
| `MCP_SERVER_URL` | `http://localhost:4001/mcp` | Streamable HTTP endpoint of `mcp-server` used by `/chat`. |
