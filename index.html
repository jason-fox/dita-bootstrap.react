DITA Harness User Guide

User guide for viewing, rendering, querying, and chatting with DITA documentation rendered by a React web application with a RAG Vector Search service, and AI Assistant.

Welcome to the DITA Harness

The DITA Harness provides an interactive web application for browsing DITA documentation, viewing rich Bootstrap components, querying content via semantic vector search (RAG Service), and chatting with an AI Assistant. Content is published from DITA source files and automatically rendered in modern web browser views.

Publishing & Adding Documentation

Adding documentation to the library involves two primary publishing tasks:

  1. Generating AST: Publish your DITA map using the ast-bootstrap format directly into the data store output folder: 
    dita --input=path/to/your.ditamap \
     --format=ast-bootstrap \
     --output=react-harness/data-store/data/my-doc-set
    See generating-ast.dita for detailed instructions on AST publishing and custom header/footer include templates.
  2. Generating Chrome: Generate global fallback chrome layouts using the ast-chrome format and sync chrome.json: 
    dita --input=path/to/your.ditamap \
     --format=ast-chrome \
     --output=path/to/output

rsync -a --delete path/to/output/chrome.json react-harness/data-store/data/chrome.json
    See generating-chrome.dita for detailed instructions on overridable chrome elements.

The system automatically detects published document sets, builds search indices, and displays them in your documentation catalog.

Quick Start with Docker Compose

Launch the complete React Harness documentation system (data-store, renderer, mcp-server, and optional rag-service) using Docker Compose:

# Launch all documentation services in the background
docker compose up -d

Once launched, access the system services in your browser:

  • Documentation Portal: http://localhost:3100 — View and browse loaded documentation sets.
  • AI Assistant Chat: http://localhost:3100/chat — Chat with the AI documentation assistant.
  • RAG Vector Search Service: http://localhost:4002/health — Check semantic vector search status.

Viewing, Rendering & Navigation Features

The web reader offers rich interactive controls for viewing and reading documentation:

Documentation Library Portal (/)
A visual catalog displaying all published document sets. Select any card to open its topic reader view.
Collapsible Navigation Sidebar
A multi-level Table of Contents sidebar for expanding chapters and navigating directly between topics.
Interactive Component Rendering
DITA elements (tables, accordions, alerts, badges, cards, code blocks, figures) render as live interactive Bootstrap components with column sorting, text filtering, and pagination.
RAG Vector Search & Header Search Bar
Type keywords into the header search bar or chat prompt to query topics. Requests leverage the standalone RAG Service for high-speed semantic vector ranking.
Dark Mode Switcher
Toggle between Light, Dark, and System Auto color themes via the header menu.
AI Assistant Chat (/chat)
Chat with an AI Assistant to answer questions about the documentation corpus or preview interactive topic components inline.

User Configuration (.env)

Customize site theme and AI Assistant credentials using environment variables in your .env file:

BOOTSTRAP_THEME
Selects the visual theme (e.g. default, journal, darkly, flatly, cyborg).
CHAT_BOT_PROVIDER
Active AI provider: gemini, anthropic, openai, or ollama.
GEMINI_API_KEY
API authentication key for Google Gemini AI Chat capabilities.
SHOW_TOOL_INVOCATIONS
Set to true to display expandable details for AI tool execution in chat threads.
