RAG Service API

Overview

Optional hybrid search service for AST-rendered DITA content. Chunks each topic along heading boundaries, embeds the chunks with a local model chosen at image build time (EMBED_MODEL), and ranks results by fusing embedding similarity with BM25.

mcp-server delegates search_documentation to this service when RAG_SERVICE_URL is set, and falls back to MiniSearch on any non-OK or empty response.

Startup: the service accepts connections immediately, but POST /api/search returns 503 until the first indexing pass completes.

Index freshness: data-store calls POST /api/reindex after doc set uploads and deletes when its own RAG_SERVICE_URL is set. Reindexing is incremental (SHA-256 per topic).

RAG Service - Search

Hybrid embedding and keyword search over topic chunks

Runs an embedding search and a BM25 keyword search over all chunks, merges the two rankings with reciprocal rank fusion, and returns the best chunk per topic.

RAG Service - Indexing

Keep the RAG index in step with the data store

Scans the data directory, re-embeds topics whose content hash changed, and purges topics that are no longer listed in their doc set's toc.json. Calls are serialised, and the response is sent when the pass finishes, which can take minutes for large uploads.

Responses

HTTP CodeDescriptionSchema
200 Reindex complete object
500 Reindex failed RagError

Produces

  • application/json
