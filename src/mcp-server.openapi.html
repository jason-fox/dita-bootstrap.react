MCP Server API

Overview

Model Context Protocol server for AST-rendered DITA documentation, exposed over the Streamable HTTP transport (--transport http). The stdio transport has no HTTP surface.

All MCP traffic is JSON-RPC 2.0 on a single endpoint, /mcp. A client opens a session with an initialize request (no session header); the response carries an Mcp-Session-Id header that must accompany every later request. Idle sessions are reaped after 30 minutes.
