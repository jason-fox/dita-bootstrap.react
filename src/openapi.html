Data Store API

Overview

Static file server and document set manager for AST-rendered DITA content. Serves both topic data (JSON) and manages document collections via zip uploads.

Authentication: Optional bearer token (set AUTH_TOKEN env var). Write operations (POST, PUT, DELETE on /api/docs/*) require auth when enabled.

Search Index: Built automatically on startup and after each doc set upload.

Version: 1.0.0
